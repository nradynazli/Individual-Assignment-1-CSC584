# Personal Profile Web Application (CSC584 Individual Assignment 1)

## Description
A simple Java Web Application developed using HTML, Java Servlet, and JSP. The application collects user profile information via an HTML form, processes the HTTP POST request using a Servlet, and displays the information dynamically on a JSP page.

## Technologies Used
- *Frontend:* HTML5, CSS3
- *Backend:* Java Servlet, JSP (Java EE)
- *Server:* GlassFish
- *IDE:* NetBeans

## Software & Hardware Requirements
-*JDK**: JDK 8 or higher
-*IDE**: Apache NetBeans IDE
-*Web Server**: GlassFish Server
-*Web Browser**: Google Chrome or Microsoft Edge
